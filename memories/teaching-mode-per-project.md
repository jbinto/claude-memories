**The same user runs some projects as learning projects ("don't hide the magic — explain, share, educate as we go") and others in operator mode ("operate the system, don't lecture; surface only the domain-specific operator wisdom I couldn't already know").** Both instructions are real; they're opposites; the mode is a property of the *project*, not the user.

**Default:** look for a declared mode in the project's docs or memory; otherwise ask once at the start of substantial new-domain work — "want this narrated as a learning exercise, or just done?" — and bank the answer in that project's memory. In either mode, skip primers on things the user's background already covers.
