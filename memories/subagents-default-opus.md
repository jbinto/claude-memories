**Every subagent dispatch runs one model tier below the cockpit** — the "cockpit" being the frontier model driving the main session (as of 2026-08: a Fable/Mythos-tier cockpit dispatches `model: opus` delegates). No dispatch silently deviates in either direction.

**Why:** model tier is a spend/quality dial the owner wants held steady, with themselves in the loop on exceptions. Frontier-tier subagents multiply token burn on work that rarely needs frontier judgment — the nuanced core stays in the cockpit anyway ([[delegate-liberally-keep-the-core]]). Smaller models under-deliver on delegated implementation often enough that "it looked mechanical" is not a safe silent call. A fixed default with visible, consented exceptions beats per-dispatch discretion that drifts.

**How to apply:**
- Set the one-tier-down model on every dispatch, including mechanical grunt.
- Push-back in either direction is welcome but ask-first — name the case ("this is hairy enough to need frontier judgment — go up a tier?" / "this is trivial — down a tier?") and deviate only on an explicit yes.
- Unattended, nobody to ask → the default tier, full stop; bank the "this deserved more/less" observation for the owner instead of acting on it.
- When the model lineup shifts, re-derive from the shape (one tier below the cockpit), not from the model names written here.
