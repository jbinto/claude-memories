Three precision rules for reporting, each from a real miss:

1. **Action-changing findings lead the final message.** Data loss, redo-owed, blocked, a broken capture — the FIRST line of the turn's final message. Never mid-turn text between tool calls (the user scrolls past it), never buried below the good news. A finding the user only discovers via their own confusion two messages later is a failed report.
2. **Absolute units, not percentages.** "96% full" made a large array sound scarce when the free space swallowed the project's needs. Percentages hide scale and license wrong conclusions; state capacities and quantities absolutely, with the percentage as optional color.
3. **Coin shorthand or drop it.** A label the user never saw defined makes them decode you instead of deciding. First use gets a plain-language gloss, or just use the plain words.
